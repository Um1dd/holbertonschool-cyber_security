# CVE Research: MS17-010 (CVE-2017-0144)

## 1. What is the CVE ID for the vulnerability?
* **CVE ID:** CVE-2017-0144

## 2. Provide a detailed description of the vulnerability.
* **Description:** A remote code execution vulnerability exists in the Microsoft Server Message Block 1.0 (SMBv1) server when it improperly handles certain crafted packets, allowing authenticated or unauthenticated attackers to execute arbitrary code on the target system.

## 3. What is the CVSS score for this vulnerability?
* **CVSS Base Score:** 8.1 / 9.8 (Critical)

## 4. What are the potential impacts of exploiting this vulnerability?
* **Impact:** Complete system compromise, remote code execution with SYSTEM privileges, and potential for widespread malware propagation (such as WannaCry or NotPetya ransomware).

## 5. Are there any known mitigations or patches available for this vulnerability?
* **Mitigation/Patch:** Microsoft released security update MS17-010. Additional mitigations include disabling SMBv1, blocking TCP port 445 at the network perimeter, and applying the vendor patches.
